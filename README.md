# Unit Converter

A simple desktop unit converter app built with Python and PySide6 (Qt framework).

## What it does
Converts between the following units:
- Kilometers ↔ Miles
- Kilograms ↔ Pounds
- Celsius ↔ Fahrenheit

## How to run it

Make sure you have Python installed, then install PySide6:

pip install pyside6

Then run the app:

python main.py

## Built with
- Python 3
- PySide6 (Qt for Python)
